# Epomaker RT82 QMK Firmware

Custom QMK firmware for the **Epomaker RT82** mechanical keyboard, based on the EastSoft FS026 ARM Cortex-M0 MCU with ChibiOS RTOS.

## Quick Start

### Prerequisites

- `arm-none-eabi-gcc` (tested with 10.1.0 and 14.2.1)
- [QMK CLI](https://docs.qmk.fm/#/newbs_getting_started) (`pip install qmk`)
- Linux (for flashing via LUFA Mass Storage bootloader)

### Clone

```bash
git clone --recurse-submodules -b rt82 git@github.com:guysoft/qmk_firmware.git
cd qmk_firmware
```

The `--recurse-submodules` flag is required -- the ChibiOS and ChibiOS-Contrib submodules contain Epomaker-specific FS026 MCU patches that are hosted on dedicated `rt82` branches of `guysoft/ChibiOS` and `guysoft/ChibiOS-Contrib`.

### Compile

```bash
qmk compile -kb epomaker/epomaker_rt82 -km via
```

This produces `epomaker_epomaker_rt82_via.bin` (~78 KB) in the repo root.

> **Note:** Only the `via` keymap should be used. The `default` keymap will not link because the proprietary `librdrcommon.a` library requires RAW HID and Dynamic Keymap features that are only enabled by the `via` keymap's `rules.mk`.

### Flash

The RT82 uses a **LUFA Mass Storage bootloader** (not DFU). The keyboard appears as a small USB block device (~106 KB FAT12 virtual disk).

#### Enter Bootloader Mode

Use one of these methods:

1. **Fn + Right Shift + Esc** (if running QMK firmware)
2. **Hold Escape while plugging in USB** (also erases persistent settings)

#### Identify the Device

```bash
dmesg | tail -20
```

Look for:
```
usb x-x.x: Product: RDMCTMZT DFU
usb x-x.x: Manufacturer: LUFA Library
sd x:x:x:x: [sdX] 212 512-byte logical blocks: (109 kB/106 KiB)
```

Note the device (e.g., `/dev/sdd`). Verify it is ~106 KiB:

```bash
lsblk /dev/sdX
```

#### Write the Firmware

The firmware binary must be padded with 0x1A00 (6656) zero bytes to account for the bootloader region, then written to the block device starting at sector 7 (the FAT12 data region):

```bash
# Create padded binary
dd if=/dev/zero bs=1 count=6656 > padded.bin
cat epomaker_epomaker_rt82_via.bin >> padded.bin

# Write to device (replace sdX with your device)
sudo dd if=padded.bin of=/dev/sdX bs=512 seek=7 conv=notrunc
sudo eject /dev/sdX
```

Alternatively, use the `compile_flash.sh` helper script which automates device detection, padding, and safety checks:

```bash
# From the rt82 workspace directory:
./compile_flash.sh via                # Compile and flash
./compile_flash.sh --flash-only firmware.bin  # Flash a pre-built binary
```

#### Verify

After reboot, the keyboard should enumerate as a normal USB HID device:

```bash
lsusb | grep -i 36b0
# Expected: Bus xxx Device xxx: ID 36b0:30a3
```

## Hardware Details

| Property | Value |
|---|---|
| MCU | EastSoft FS026 (ARM Cortex-M0) |
| Matrix | 6 rows x 16 columns, ROW2COL |
| LEDs | 82 RGB LEDs (custom driver via `librdrcommon.a`) |
| Encoder | Rotary encoder with encoder map |
| Debounce | `asym_eager_defer_pk`, 5ms |
| NKRO | Forced on |
| Bootloader | LUFA Mass Storage (VID:PID `03EB:2045`) |
| Normal USB | VID:PID `36B0:30A3` |

## Repository Structure

```
keyboards/epomaker/epomaker_rt82/
├── config.h              # Hardware configuration
├── epomaker_rt82.c       # Board initialization
├── info.json             # QMK keyboard definition (matrix, USB, RGB)
├── rules.mk              # Build options (FS026 board, custom EEPROM/Bluetooth)
├── halconf.h             # ChibiOS HAL configuration
├── mcuconf.h             # MCU-specific peripheral config
├── chconf.h              # ChibiOS kernel configuration
├── ld/                   # Linker scripts for FS026
│   ├── FS026.ld
│   └── FS026_booter.ld
└── keymaps/
    ├── default/          # Minimal keymap (does not build standalone)
    └── via/              # VIA-compatible keymap (use this one)
        ├── keymap.c
        ├── config.h
        └── rules.mk

lib/rdr_lib/
├── librdrcommon.a        # Precompiled proprietary library (wireless, RGB, battery, display)
└── rdr_common.h          # Header for the proprietary library
```

### Key Dependencies

| Submodule | Fork | Branch | Purpose |
|---|---|---|---|
| `lib/chibios` | `guysoft/ChibiOS` | `rt82` | ChibiOS RTOS with Epomaker FS026 patches |
| `lib/chibios-contrib` | `guysoft/ChibiOS-Contrib` | `rt82` | FS026 HAL port (GPIO, USB, SPI, UART, timers, etc.) |

Other submodules (`lib/googletest`, `lib/lufa`, `lib/vusb`, `lib/printf`, `lib/pico-sdk`, `lib/lvgl`) use upstream `qmk/*` repositories and clone normally.

### Proprietary Library

The `lib/rdr_lib/librdrcommon.a` is a precompiled ARM Cortex-M0 static library provided by Epomaker. It handles wireless connectivity, RGB LED control, battery management, and display functions. The header `rdr_common.h` defines the public API. This library cannot be rebuilt from source.

## Build Notes

- The `platform.mk` was patched to include `$(OSLIBSRC)` in `PLATFORM_SRC`, fixing linker errors for ChibiOS memory core functions.
- The `.gitignore` has a global `*.a` rule; `librdrcommon.a` is force-tracked with `git add -f`.
- GCC 14.2.1 produces working firmware (confirmed on hardware). No need for the older GCC 10.1.0 that Epomaker used on Windows.

## Troubleshooting

- **Keyboard not responding after flash:** Unplug, hold Escape, plug back in to re-enter bootloader mode and flash again.
- **Linker error `cannot find -lrdrcommon`:** Make sure you cloned with `--recurse-submodules` and that `lib/rdr_lib/librdrcommon.a` exists. If it's missing, the `.gitignore` may have interfered -- run `git checkout -- lib/rdr_lib/librdrcommon.a`.
- **Linker errors about `chCoreAllocFromBase` or `__core_init`:** The `$(OSLIBSRC)` fix in `platforms/chibios/platform.mk` may be missing. Ensure you're on the `rt82` branch.
- **Default keymap won't compile:** This is expected. Use `-km via` instead.
